# Medical Disease Prediction

## 📌 Project Overview

Medical Disease Prediction is a Machine Learning project that predicts a possible disease based on the symptoms provided by the user.

The project includes data preprocessing, exploratory data analysis (EDA), feature selection, model training, model evaluation, and deployment using Flask.

## 🎯 Objective

The main objective of this project is to build a Machine Learning model that can analyze medical symptoms and predict the most likely disease.

🔄 Project Workflow
1. Collect the medical disease dataset
2. Clean and preprocess the data
3. Perform Exploratory Data Analysis (EDA)
4. Prepare features and target variable
5. Train different Machine Learning models
6. Evaluate model performance
7. Select and save the best-performing model
8. Develop a Flask web application
9. Take symptoms as user input
10. Predict the possible disease
